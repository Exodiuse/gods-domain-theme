# God's Domain — Forumactif theme

Feuilles de style externes du thème Forumactif God's Domain.

## Fichiers
- `css/base.css` : base Blank Theme + styles globaux
- `css/index.css` : page d'accueil
- `css/viewforum.css` : affichage d'un forum + liste des sujets
- `css/viewtopic.css` : affichage d'un sujet + messages
- `css/responsive.css` : règles responsive
